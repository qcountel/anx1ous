# anx1ous

Внутренний клиент (DLL) для **Minecraft: Windows 10 Edition 1.1.5** с оверлей-интерфейсом в стиле Java-клиентов: ClickGui по `Insert`, HUD- и визуальные модули, JSON-конфиги. Внедряется в процесс игры и рисует интерфейс поверх кадра через Direct2D/D3D11.

Форк проекта **[Aerial]([https://github.com/](https://github.com/xan6x/Aerial))**.

> ⚠️ Нацелен строго на билд `1.1.5` — на других версиях DLL не активируется.

## Управление

| Клавиша | Действие |
|---|---|
| `Insert` | Открыть/закрыть меню |
| `End` | Выгрузить DLL |

## Сборка

Требуется Visual Studio 2022 (MSVC) и CMake 3.21+:

```bat
build.bat          :: инкрементальная сборка Release
build.bat clean    :: пересборка с нуля
```

Готовая библиотека: `build\bin\Release\anx1ous.dll`.

## Дисклеймер

Проект создан в образовательных целях. Использование сторонних клиентов может нарушать правила серверов и условия использования игры.
