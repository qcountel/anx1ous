# anx1ous

Внутренний клиент (DLL) для **Minecraft: Windows 10 Edition 1.1.5** с оверлей-интерфейсом в стиле Java-клиентов: ClickGui по `Insert`, HUD- и визуальные модули, JSON-конфиги. Внедряется в процесс игры и рисует интерфейс поверх кадра через Direct2D/D3D11.

Форк проекта **[Aerial](https://github.com/xan6x/Aerial)** — переименован, доработан (исправления рендера курсора в меню, чистка сборки) и продолжает развиваться.

> ⚠️ Нацелен строго на `1.1.5` — на других версиях DLL не работает.

## Управление

| Клавиша | Действие |
|---|---|
| `Insert` | Открыть/закрыть меню |
| `End` | Выгрузить DLL |
